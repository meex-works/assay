# Tutorials

Step by step, in order. Each one says what you'll end up with, and ends with a check that it worked.

| | tutorial | you'll end up with |
|---|---|---|
| 1 | [Your first dry run](01-quickstart.md) | assay judging live launches on your computer, printing what it would post |
| 2 | [Getting the keys](02-keys.md) | a gRPC stream, a websocket and an RPC, tested |
| 3 | [Your Telegram channel](03-telegram.md) | a bot, a channel and a discussion group, posting for real |
| 4 | [Configuration](04-configuration.md) | every switch and threshold understood, and recipes for common setups |
| 5 | [Running it on a server](05-server.md) | assay running around the clock under systemd, with logs, updates and backups |
| 6 | [The website](06-website.md) | your own copy of assay.meex.work on your domain |
| 7 | [Operating it](07-operating.md) | reading the report, querying the database, fixing what breaks |

Video walkthroughs of tutorials 1, 3, 5 and 6: [assay.meex.work/tutorials](https://assay.meex.work/tutorials).

Stuck? `npm run doctor` checks everything the enabled modules need and prints the fix for each problem. Still stuck,
or disagree with a rule? [X](https://x.com/meexworks) · [Telegram](https://t.me/meex_the_dev).
